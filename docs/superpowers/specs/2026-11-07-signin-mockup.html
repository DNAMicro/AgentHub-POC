What happens behind the page

  1. Every address of the app — pages, the guide, /api/* and the live streams — asks for a signed-in session first. Pages send you to /signin; API calls get 401.
  2. Only the sign-in page, its stylesheet and the two font files load without signing in.
  3. Passwords are never stored — only a salted scrypt hash, in a file that is not in git.
  4. The session cookie can't be read by page scripts and is sent only over HTTPS.
